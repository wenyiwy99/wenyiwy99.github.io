<font size = 3><h5>TrajEvolve: Trajectory Evolution for Reinforcement Learning with Hindsight Credit Assignment</h5></font>

**Yi Wen**<sup>*</sup>, Hao Chen<sup>*</sup>, Wanyu Wang, Maolin Wang, Pengyue Jia, Derong Xu, Huize Tan, Yingyi Zhang, Wenlin Zhang, Weihong Luo, Xiku Du, Xiangyu Zhao<sup>#</sup>. [**PDF**](https://wenyiwy99.github.io/) [**Code**](https://github.com/wenyiwy99/TrajEvolve)

- We propose TrajEvolve, which determines the necessary steps of successful trajectories via hindsight verification, trains a step-level credit discriminator, and evolves trajectories during RL by pruning redundancy, correcting format errors, and rolling back action errors.

<font size = 3><h5>Memory Type Varies: Empowering LLM Agents for Long-Term Memory with Diverse Strategies</h5></font>

**Yi Wen**, Derong Xu, Pengyue Jia, Yichao Wang<sup>#</sup>, Yingyi Zhang, Maolin Wang, Junyi Li, Wenlin Zhang, Xiaopeng Li, Yong Liu, Xiangyu Zhao<sup>#</sup>. [**PDF**](https://arxiv.org/pdf/2610.11573) [**Code**](https://github.com/wenyiwy99/MemoType) [**Cite**](https://scholar.googleusercontent.com/scholar.bib?q=info:IUKCOUEGKVUJ:scholar.google.com/&output=citation&scisdr=CiAIef71EJmMyx-2hQw:ACTRDVEAAAAAatewnQycFzQUlkEaXhx8IyuS-1I&scisig=ACTRDVEAAAAAatewnStADUt0H0mez7rnQPF9LQ4&scisf=4&ct=citation&cd=-1&hl=en)

- We construct TriMEM, a memory multi-class dataset with Episodic, Personal Semantic, and General Semantic memory annotations, and propose MemoType, which routes each memory and query to its type and applies a tailored retrieval strategy, achieving up to 16.18% improvement in Recall@1.
</div>

<font size = 3><h5>Scalable Incomplete Multi-View Clustering with Structure Alignment</h5></font>

**Yi Wen**, Siwei Wang<sup>#</sup>, Ke Liang, Weixuan Liang, Xinhang Wan, Xinwang Liu<sup>#</sup>, Suyuan Liu, Jiyuan Liu, En Zhu. [**PDF**](https://arxiv.org/pdf/2308.16541.pdf) [**Code**](https://github.com/wenyiwy99/SIMVC-SA)
